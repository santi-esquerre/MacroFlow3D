## Scientific analysis — the eta=1 gauge degeneracy (hypothesis, falsifiable)

The streamfunction pair is a Clebsch/Euler-potential representation
(paper eq. 13; M = 1 by integrability). Such representations are NOT
unique for a given velocity field (Lester et al. 2021, cited by the paper
at its eq. 19: the mean components "may be chosen as such due to
non-uniqueness of the streamfunctions"). Concretely, any label
recombination `(psi1, psi2) -> (f(psi1,psi2), g(psi1,psi2))` with unit
label-Jacobian (`f_1 g_2 - f_2 g_1 = 1`) preserves
`v = grad(psi1) x grad(psi2)` exactly. Because eq. (14) is derived FROM
that representation plus the Darcy constraint, every such pair of the SAME
`v` solves the full nonlinear system at `eta = 1`.

Infinitesimally, the tangent space of this solution manifold is spanned by
`delta psi_i` generated by divergence-free (area-preserving) vector fields
on the label torus, subject to compatibility with the affine parts
(periodicity in the labels with the affine periods). This is a
LARGE-dimensional family — not one soft mode. Our mean-zero gauge removes
only the two additive constants; it does not touch the recombination
freedom.

Consequences, all matching the observations:

- At `eta = 1` the (regularized) Jacobian has a CLUSTER of near-zero
  eigenvalues at the solution — the same spectral object as the Picard
  multiplier reaching ~1 (the SF-21 contraction boundary).
- At `eta < 1` the homotopy blend `rhs_affine - eta*q*S` breaks the exact
  invariance, separating the cluster from zero — exactly the observed
  cliff (Newton superb at `eta = 0.98..0.997`, grinding only at 1).
- The epsilon-regularized denominator and the coupling strength (which
  grows with `sigma_Y^2` and `lambda`) modulate how closely the
  regularized system approaches the exact degeneracy — matching the
  sigma^2/lambda dependence (`0.25` converges at `eta = 1`; `>= 1` beyond
  `lambda ~ 0.5` does not).
- It explains the PAPER'S OWN METHOD choice (§5.1): explicit pseudo-time
  flows onto the solution manifold without ever inverting `J`; tangential
  singularity is harmless to a flow method. Our Newton divergence hit
  exactly the structure the paper's method sidesteps.

The hypothesis is falsifiable and the new increment's activation gate
tests it directly (see D-gate below).

## The unifying mechanism and its wiring (why this aligns with the current solver)

Both selected methods replace the Newton system by the SHIFTED system

    (mu * A_blk + J) delta = -F,      A_blk = diag(A, A),  A = -div(q grad)

- **Spectrum:** with the accepted block-MG preconditioner `M ~ A_blk`,
  `M^-1 (mu A_blk + J) ~ mu I + M^-1 J` — the near-null cluster of
  `M^-1 J` moves to `~mu`. GMRES convergence is restored WITHOUT touching
  the preconditioner. This is the key alignment: the shift is taken in the
  A-metric precisely so the existing SF-23 preconditioner keeps working.
- **Wiring cost (verified against the code):** the shifted apply is
  `jvp.apply(...)` plus `mu * A p_i` per component — the A-apply exists
  (`operators::LesterPositiveDiffusionOperator`). `CoupledGmres::solve`
  currently hard-types `JvpWorkspace&`; it gains a duck-typed operator
  template parameter (defaulted to `JvpWorkspace`, zero impact on accepted
  call sites — the same pattern its Preconditioner parameter already
  uses). A small `ShiftedJacobianOperator` wrapper (one 2n scratch, exact
  bytes) provides the combined apply.
- **Schedules:** LM: `mu_k = theta * r_F_k` (theta calibrated by the
  D-gate mu-sweep; superlinear under the error bound). Ψtc/SER
  contingency: `mu_k = 1/dtau_k`, `dtau_{k+1} = dtau_k * r_F_{k-1}/r_F_k`.
  `theta = 0` recovers the accepted SF-24 pure-Newton path bitwise —
  the terminal schedule is opt-in and the existing behavior is its
  special case.
- **Globalization unchanged:** the E6 rescue/retry protocol, the identical
  trial guard chain, and Armijo on `0.5*r_F^2` all stay (LM directions are
  descent directions for `||F||` near the manifold under the error bound).
  A non-monotone SER acceptance would be a separate, explicitly recorded
  decision — only if the contingency is triggered.
- **Convergence target:** any point of the manifold is scientifically
  valid — every Gate-3A acceptance metric (`e_v`, invariance errors,
  divergence, |c| percentiles, r_F itself) is gauge-invariant. Landing
  anywhere on the manifold satisfies the physics.

## The D-gate (diagnostic-first, activation-gated, falsifiable)

Before any solver code, the new increment must freeze a genuine plateau
state (deterministic: warm-start the `lambda = 0.5125` problem from the
accepted `(lambda=0.5, eta=1)` smoke state and run Picard/Anderson to the
stagnation exit) and measure:

1. **mu-sweep:** solve `(mu A_blk + J) delta = -F` at
   `mu in {1e-1, 3e-2, 1e-2, 3e-3, 1e-3, 3e-4, 1e-4, 0}` with the
   accepted GMRES (restart 10, budget 100), recording
   iterations-to-tolerance / achieved reduction. MECHANISM CONFIRMED iff
   some `mu > 0` restores convergence with >= 10x fewer iterations than
   `mu = 0` (which is known to budget-exhaust).
2. **Spectral probe:** shifted power iteration on `I - c M^-1 J`
   (matrix-free, existing pieces) to estimate the magnitude of the
   smallest preconditioned modes — direct evidence for/against the
   near-null cluster.
3. **LM mini-solve:** with theta from (1), a bounded shifted-Newton run at
   the frozen state must exit the plateau (r_F <= 1e-4, i.e. 10x below
   the observed floor).

If (1) fails, the shift hypothesis is FALSIFIED and the increment reports
BLOCKED with the spectral evidence; the recorded next research direction
is the gauge-fixed/bordered formulation. No gate of any downstream
increment may be weakened in either case.
