# SF-33 artifact: GPU inlet-label streamfunctions

Evidence of increment SF-33 (GPU implementation of the SF-29 inlet-label formulation of equation (14) on the
`x1`-non-periodic slab). The experiment note is
[`../../2026-10-06-sf33-gpu-inlet-labels.md`](../../2026-10-06-sf33-gpu-inlet-labels.md); this README only says
what is where and how to regenerate it. Use it to find the file behind a number of the note; do not use it as a
result summary.

- Code (not in this directory): `src/physics/streamfunctions/inlet_slab/`, driver `apps/inlet_slab/`
  (`inlet_slab`), fast tests `tests/inlet_slab/` (`ctest -R inlet_slab_`).
- Increment spec: `docs/plans/active/lester-eq14/increments/SF-33-gpu-inlet-label-streamfunctions.md`.

## Exports: layout and regeneration

Layout: [`scripts/README.md`](scripts/README.md), section "Output layout" (case directories
`<field>_<eps>_<N>/`, `stage/<amp>/`, `solutions/<case>_i1o4/`, `crosscheck_<field>_<eps>_<N>/`; slab arrays
`(N+1, N, N)`, `m3` fastest). Campaign B adds `exports/oracle_gpu/N<N>/psi_or_{1,2}*.npy` (`--save-oracle`).
Regeneration (deterministic; run from `scripts/`):

```bash
python3 export_proto.py --selftest
python3 export_proto.py gauss:0.25:16 gauss:0.25:24 gauss:0.25:32 gauss_ch:0.25:16 ... --out ../exports
python3 export_proto.py --solutions ../../2026-10-02-sf29-inlet-labels/raw/sweep2/solutions/<case>_16_i1o4.npz \
        --out ../exports/solutions
python3 export_proto.py --crosscheck gauss:0.25:16 gauss:0.25:24 gauss:0.25:32 --out ../exports
# 24^3 full-precision references (SF-29 prototype, CPU, ~7-60 min each on the V100 host)
cd ../../2026-10-02-sf29-inlet-labels/scripts
python3 candidate_i.py <field>:<eps>:24:i1o4 --direct-max 32 --reuse-lu 0 --save ~/sf33_ref24
cd - && python3 export_proto.py --solutions ~/sf33_ref24/*.npz --out ../exports/solutions
```

24^3 / 32^3 exports need the SF-29 oracle caches (minutes of CPU per case, written by `cases.load_case` into the
SF-29 `raw/cache/`, gitignored there); run them as detached V100 jobs, not locally.

Anyone syncing the SF-33 mirror again must repeat that save/restore or regenerate the exports.
